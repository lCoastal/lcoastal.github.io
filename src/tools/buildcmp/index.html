Compare Builds

Put in the luck and capacity of two or more builds, pick a mineral, and see how many pans each build needs to find it.
Uses the same luck model as Luck Odds.

Heads up: builds are compared with the same luck model as Luck Odds, at about √capacity minerals per pan. Modifiers, Size Boost, enchants, events and weather aren't counted yet, so use this to see which build wins rather than exactly by how much. Add your pans per hour too, since bigger pans usually take longer.
