Compare Builds

Put in the luck and capacity of two or more builds, pick a mineral, and see how many pans each build needs to find it.
Uses the same luck model as Luck Odds.

⚠ THE LUCK FORMULA IS STILL AN ESTIMATE
It's fitted on testing, not the game's real formula. It matches most minerals closely, but some can still be off, especially the rarest ones. Treat the numbers here as a guide, not exact odds. Every test is in the Test Log.

Load a build sheet into a build to work out its luck and capacity from its gear with your Stat Calculator boosts, and see exactly what differs.

Heads up: builds are compared with the same luck model as Luck Odds (bigger pans hold more minerals, but not in proportion). Modifiers, enchants, events and weather aren't counted yet, so use this to see which build wins rather than exactly by how much. Add your pans per hour too, since bigger pans usually take longer.

How it works

  • Each build uses the same drop model as Luck Odds: luck gives extra tries at the zone's drop table, and capacity sets how many minerals each pan holds.
  • With a luck cap on, the build counts as having a bit less luck than the cap's number, because capped pans behave that way in game.
  • "Best zone" gives each build the zone where it finds the mineral most often, so two builds can end up in different places. The Void is only used when nowhere else drops it.
  • Pans per hour is optional: fill it in to turn pans into time.
